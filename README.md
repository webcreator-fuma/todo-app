# 制作物まとめ

自己紹介ページ：https://webcreator-fuma.github.io/todo-app/

HTML・CSS・JavaScriptで作った、小さなWebアプリ集です。

## 1. ToDoアプリ
https://webcreator-fuma.github.io/todo-app/todo.html

- やることの追加と削除
- 完了した項目に取り消し線
- ブラウザを閉じても内容が残る(ローカルストレージ)

## 2. ポモドーロタイマー
https://webcreator-fuma.github.io/todo-app/timer.html

- 25分のカウントダウン
- スタートとリセット
- 時間になるとお知らせを表示

## 3. 電卓
https://webcreator-fuma.github.io/todo-app/calc.html

- 四則演算と小数点の計算
- Cボタンでリセット
- ボタン配置にCSS Gridを使用

## 4. おみくじ
https://webcreator-fuma.github.io/todo-app/omikuji.html

- ボタンを押すと結果が出る
- 結果は6種類
- CSSで装飾

## 5. じゃんけん
https://webcreator-fuma.github.io/todo-app/janken.html

- ボタンを押すとコンピューターと勝負ができる
- コンピューターの手はランダムで決まる
- 勝ち、負け、あいこが決まる
- 自分の勝ち数、負け数を数える
- 勝ち数、負け数はブラウザーに保存されていてリセットボタンで消せる

## 6. 数当てゲーム
https://webcreator-fuma.github.io/todo-app/guess.html

- ランダムに隠した数字を当てる
- 入れた数字より大きいか小さいかヒントが出る
- 何回で当てたか表示される
- 何回でも遊びなおせる

## 使用技術
HTML / CSS / JavaScript

## 学んだこと
- 入力を受け取って画面に反映する仕組み
- データの保存と復元
- 時間で動く処理(setInterval)
- ボタンの押下を式として組み立てて計算する処理
- GitHub Pagesでの公開
